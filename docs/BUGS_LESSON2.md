## 🔴 Критично

### [x] C1. Разделитель `---` печатается ребёнку как текст «---»
- **Где:** `js/lesson-data-security.js` - 23 строки `---` внутри `taskMd` (во всех 13 шагах).
- **Симптом:** между «Пунктами действия» и телом задания стоит абзац с тремя дефисами.
- **Причина:** `js/markdown.js` не знает горизонтальной черты: строка `---` не совпадает
  ни с заголовком, ни со списком и уходит в обычный абзац (`markdown.js:92`).
- **Как чинить:** поддержать `---` → `<hr>` в парсере + стиль в `css/markdown.css`.

### [x] C2. Блок «📋 Пункты действия» склеивается в одну строку - во всех 13 шагах
- **Где:** каждый шаг, например `js/lesson-data-security.js:824–828`.
- **Симптом:** чек-лист «1. … 2. … 3. …» выводится сплошным абзацем через пробел -
  ровно тот же дефект, что B1 в уроке 1, но системный.
- **Причина:** парсер понимает списки только по `-`/`*` (`js/markdown.js:83`), а
  подряд идущие строки склеивает в один `<p>` (`markdown.js:42`).
- **Как чинить:** добавить в парсер нумерованные списки (`1.` → `<ol>`), с учётом
  переноса длинного пункта на следующую (отбитую пробелами) строку.

### [x] C3. Шаг «Инструменты (2/2)» нумерует пункты с 4
- **Где:** `js/lesson-data-security.js:884, 891, 901` - пункты `**4.**`, `**5.**`, `**6.**`.
- **Симптом:** шаг начинается с «4.», хотя это первый пункт шага (нумерация тянется
  из предыдущего шага, где было три пункта).

### [x] C4. «Запасной способ» отражённого XSS через консоль не работает
- **Где:** `js/lesson-data-security.js:1758` и `hintMd:1785`, шаг «Отражённый XSS».
- **Текст:** `location.hash = "welcome=<img src=x onerror=alert('Взлом!')>"` в F12 → Console.
- **Правда:** консоль DevTools по умолчанию исполняется в контексте **платформы**
  (верхняя страница `урок_2.html`), а сайт живёт в iframe. Команда поменяет адрес
  платформы - тот самый случай, про который этот же шаг пишет «дописывать к адресу
  платформы бесполезно». Ребёнок решит, что «и запасной способ не работает».
- **Как чинить:** дать команду, работающую из контекста платформы -
  `document.querySelector("iframe").contentWindow.location.hash = "welcome=…"`.

## 🟠 Ошибки в текстах

### [x] C5. Проверка «войти под admin не получится» идёт на подделанном входе
- **Где:** `js/lesson-data-security.js:1170–1175` (шаг «Дыра №2 - 🟢 почини», блок ✅).
- **Симптом:** на прошлом шаге ребёнок подделал `isLoggedIn` и `currentUser` =
  «Сам Директор». В блоке ✅ его не просят выйти, поэтому сайт по-прежнему
  показывает «👤 Сам Директор» - выглядит так, будто починка не сработала.
- **Как чинить:** в ✅ добавить пункт «нажми Выйти (или выполни
  `localStorage.removeItem('isLoggedIn')`), а потом пробуй войти под admin».

### [x] C6. Команда «просветить кладовку» выдаёт 28 КБ служебных данных платформы
- **Где:** `js/lesson-data-security.js:1824`, шаг «Бонус: флаги».
- **Текст:** `console.log(JSON.stringify(localStorage, null, 2))` → «пробеги глазами вывод».
- **Правда:** сайт делит `localStorage` с платформой, поэтому в выводе, кроме 7 ключей
  сайта, лежат `undoHistory`, `previewDoc`, `savedLessonCodeSecurity` - вместе ~28 КБ
  (замерено). «Пробежать глазами» невозможно.
- **Как чинить:** выводить только имена ключей (`Object.keys(localStorage)`) и одной
  фразой объяснить, что часть ключей - от самой платформы, а не от сайта.

### [x] C7. Таблица «что сломаем за 1 минуту» завышает цифры
- **Где:** `js/lesson-data-security.js:1592` - «только цифры (0-9) → пароль из 5-6 цифр».
- **Правда:** замер в браузере - ~8 850 догадок/с, т.е. ~500 000 в минуту. 5 цифр
  (110 тыс. вариантов) укладываются, 6 цифр (1,1 млн) - это ~2 минуты.
- **Как чинить:** «пароль из 5 цифр (6 - за пару минут)».

### [x] C8. Комментарий в коде остаётся пугать `innerHTML` после починки
- **Где:** `js/lesson-data-security.js:471` (внутри `VULN_JS`), над `showWelcome`.
- **Симптом:** шаг «Отражённый XSS» заменяет тело функции, а комментарий сверху
  по-прежнему говорит «вставляется через innerHTML - отражённый XSS». Ребёнок,
  перечитывая код, видит предупреждение о дыре, которой уже нет.
- **Как чинить:** в 🟢-блоке шага заменять функцию **вместе** с комментарием
  (и то же в `FIX_SHOWWELCOME` для админ-режима).

### [x] C9. «Научимся на шаге 1» - про вкладки файлов
- **Где:** `js/lesson-data-security.js:757` (вступление).
- **Правда:** на шаге 1 вкладки `index.html/style.css/main.js` не открывают - впервые
  это делается на шаге «Дыра №2: пароль прямо в коде» (шаг 4).
